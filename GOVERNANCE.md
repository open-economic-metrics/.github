# Governance

Open Economic Metrics is currently maintained by its founding organization owner. Contributions and feedback are welcome; creation of an organization does not imply a formal nonprofit, fiscal sponsor, or institutional endorsement.

## Decisions

- Repository maintainers manage routine implementation details within their project's documented scope.
- Changes to statistical definitions, source interpretation, public API semantics, research methods, or redistribution practices require a reviewable issue or pull request with explicit evidence.
- Accepted, consequential decisions should be recorded in a versioned decision record or research specification in the affected project. Preserve superseded decisions for historical traceability.
- Existing, source-native canonical statistical definitions must be retained when creating derived profiles.
- A merged pull request is not automatically a validated or released statistical result.

## Review and releases

Maintainers may merge their own changes while the organization has a single owner; independent review is preferred when available, but reproducible tests, benchmark reconciliation, and transparent change records are required where relevant. Do not claim independent review or verification that did not occur.

Project releases must define how they establish correctness, comparability, source permissions, and publication status. Security issues follow the [security policy](SECURITY.md); conduct reports follow the [code of conduct](CODE_OF_CONDUCT.md).

## Evolution

Maintainer roles, release authority, and review requirements can evolve with contributors and project maturity. Record governance changes openly before applying them. The organization does not promise a particular release cadence or acceptance of contributions.
