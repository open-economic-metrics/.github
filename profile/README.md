# Open Economic Metrics

**Open statistical methods. Reproducible economic measurements. Transparent data provenance.**

Open Economic Metrics is a public research initiative building reusable tools for measuring and explaining economic conditions. Its projects are designed for researchers, data analysts, developers, and people interpreting published statistics.

## Principles

- **Definitions first.** Statistical definitions are identified, versioned, and maintained as first-class resources.
- **Reproduce before extending.** Reconcile calculations with authoritative published reference results before proposing new derived indicators.
- **Respect multiple authorities.** Preserve each source's canonical definitions independently; custom profiles do not overwrite their baselines.
- **Show the evidence.** Publish methodology, denominators, populations, geography, time periods, uncertainty, and provenance with results.
- **Be honest about limitations.** Identify missing data, model-based estimates, incompatible series, and redistribution restrictions explicitly.
- **Open software, lawful data use.** Publish software and methods openly; redistribute external datasets only when permitted.

## Initial research direction

**Open Labor Metrics** is the planned initial project: a statistical measurement platform for employment, job quality, compensation, and economic adequacy. Work begins with reproducing established labor statistics and documenting source-methodology compatibility before developing new measures or dashboards.

_Research infrastructure is in setup. This description is not a claim that a public API or validated dataset is live._
