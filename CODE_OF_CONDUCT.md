# Code of conduct

Open Economic Metrics is a research-focused, collaborative community. We expect respectful, evidence-oriented participation in issues, code reviews, documentation, and discussions.

## Expected behavior

- Address ideas and evidence rather than making personal attacks.
- Welcome good-faith questions, corrections, and disagreement about methodology.
- Identify uncertainty, disclose conflicts of interest when relevant, and correct mistakes.
- Respect privacy, boundaries, and contributors' different backgrounds and levels of expertise.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, doxxing, sexualized attention, or deliberate disruption are not acceptable.

## Enforcement

Maintainers may edit or remove abusive content, request changes in behavior, restrict participation, or ban participants where appropriate. Decisions should be proportionate and documented to the extent compatible with privacy and safety.

Report abusive GitHub content using GitHub's built-in **Report** mechanisms. For a private conduct concern, contact an organization owner through a contact channel they have explicitly published; do **not** post sensitive allegations in a public issue. A dedicated private conduct-reporting contact has not yet been established. GitHub platform abuse can also be reported directly to GitHub Support.

This policy applies to official project contribution spaces. It is organization-authored guidance, not a claim of affiliation with an external code-of-conduct organization.
